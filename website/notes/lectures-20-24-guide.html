Where Apriori fits

Lecture 22: data mining → association rules → support and confidence → frequent itemsets → the Apriori algorithm. Apriori finds itemsets that meet minimum support. A rule such as Bread ⇒ Milk can then be evaluated with confidence.

Priority based on evidence

Both 2023 and 2024 ask for a worked Apriori algorithm. No comparable worked FP-tree, sampling, partition-algorithm or k-means question was identified in the five examined papers; their absence is not evidence they cannot be examined. Know their purpose and study all examinable material.

Step 3: prune and count triples

Any triple containing the infrequent pair {Milk, Sugar} cannot be frequent. The remaining candidates are {Milk, Butter, Bread} and {Butter, Bread, Sugar}; each occurs once, so neither is frequent. With no frequent triples, stop.

2023 threshold trap

That paper also has six transactions, but uses 34%: 2/6 = 33.33% is below 34%, so the minimum count is 3. For an exact percentage threshold use ceil(number of transactions × threshold); do not round 33.33% up to 34%.

Support and confidence

Support of {Bread, Milk} is the number of baskets containing both divided by all baskets. Confidence of Bread ⇒ Milk is the number containing both divided by the number containing Bread. Reversing the rule changes the denominator.

For example, if five baskets contain both 3 times, four contain Bread, and three contain Milk: support = 3/5 = 60%; confidence Bread ⇒ Milk = 3/4 = 75%; confidence Milk ⇒ Bread = 3/3 = 100%. These are calculations from an original example, separate from the 2024 paper.

OLAP patterns from the papers

Star schema and slowly changing dimensions

A fact table stores measures and foreign keys to descriptive dimension tables. State the grain: for example one row per sale line. Date, Store and Product dimensions surround the Sales fact. SCD Type 2 preserves history by adding a new dimension row with a new key; existing facts continue to reference the old row. Type 1 overwrites the value.

CUBE, ROLLUP and drill-down
GROUP BY CUBE (province, month)

CUBE yields (province, month), province totals, month totals and the grand total. ROLLUP(province, month) yields province/month, province and grand total, but not month-only totals. Drill-down moves from a summary to more detail; roll-up moves from detail to summary. In 2024 Q27, equal monthly distribution was explicitly assumed: a R15,000 quarter gives R5,000 per month.

Ranking and running totals
SELECT city, net_profit,
       RANK() OVER (ORDER BY net_profit DESC) AS profit_rank
FROM ttech_profits;

This matches the 2023 ranking pattern. With scores 100, 90, 90, 80, RANK gives 1, 2, 2, 4; DENSE_RANK gives 1, 2, 2, 3.

SELECT branch, month_no, sales_amount,
       SUM(sales_amount) OVER (
          PARTITION BY branch ORDER BY month_no
          ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW
       ) AS running_total
FROM MonthlySales;

This is an additional original practice pattern from the lecture notes, not a claim that the papers asked this exact running-total question.
