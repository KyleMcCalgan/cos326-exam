PySpark: student score analysis

Load data · Group and aggregate · Join top scorers · Try it yourself

What the activity does

Create a CSV of student scores, start a Spark session, read it into a DataFrame, calculate the average and maximum score for each subject, and join maximums back to the original rows to find the top scorers. The activity uses pandas to create the CSV; the analysis uses a Spark DataFrame.

1. Start Spark and load the data

from pyspark.sql import SparkSession
spark = SparkSession.builder.appName("Student Score Analysis").getOrCreate()

df = spark.read.csv("students.csv", header=True, inferSchema=True)
df.show(10)

header=True reads column names from the first line. inferSchema=True infers types, including a numeric type for the scores. The practical creates students.csv with pandas and includes notebook installation and findspark setup; consult the PDF for those steps. This example assumes the file exists. show(10) displays up to 10 rows.

2. Average and maximum per subject

from pyspark.sql.functions import avg, max, col

avg_scores = df.groupBy("Subject").agg(avg("Score").alias("AverageScore"))
max_scores = df.groupBy("Subject").agg(max("Score").alias("MaxScore"))

avg_scores.show()
max_scores.show()

groupBy("Subject") forms groups, agg(...) calculates an aggregate, and alias(...) names the result. The output order is not guaranteed unless explicitly sorted.

SubjectAverageMaximumTop scorer
Maths82.394Sipho
English85.595Ayanda
Science89.597Siyanda

The group result contains the subject and maximum, but not the student's name. To recover names, join those maximums back to the original rows.

3. Join to find the top scorer

d = df.alias("d")
m = max_scores.alias("m")

top_scorers = (
    d.join(
        m,
        (col("d.Subject") == col("m.Subject")) &
        (col("d.Score") == col("m.MaxScore"))
    )
    .select(
        col("d.Name").alias("Name"),
        col("d.Subject").alias("Subject"),
        col("d.Score").alias("Score")
    )
)
top_scorers.show()

The first condition matches the subject; the second matches that subject's maximum score. Both are needed: matching only the score could associate a student with the maximum of another subject. & combines PySpark column conditions, each parenthesised. If students tie for the maximum in a subject, all matching students are returned.

Connect it to SQL and MongoDB

-- SQL: average per subject
SELECT Subject, AVG(Score) AS AverageScore
FROM students
GROUP BY Subject;

// MongoDB: the same grouping idea
db.students.aggregate([
  { $group: { _id: "$Subject", AverageScore: { $avg: "$Score" } } }
])

The languages differ, but each groups records by subject and calculates an aggregate.
