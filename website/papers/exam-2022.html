Question 11 markObject ODBMSPDF p.3 ↗

Which one of the following classes would you use to connect to the ObjectDB database?

  1. Query
  2. TypedQuery
  3. EntityManager
  4. Serializable
Show answer Study answer

c. EntityManager. In ObjectDB (JPA) you open the database with an EntityManagerFactory and then get an EntityManager from it. The EntityManager is the object you use to work with the database: store (persist), find, remove, start and commit transactions, and create queries.

Query and TypedQuery only run queries once you already have an EntityManager; Serializable is a plain Java marker interface.

Question 21 markObject relational DBMSPDF p.3 ↗

Given that the following SQL statements have been executed on a PostgreSQL database:

CREATE TYPE InventoryItem AS ( name text, supplierID char(5), unitPrice numeric);
CREATE TABLE StockOnHand ( item inventoryItem, quantity integer);

CREATE FUNCTION stockValue( inventoryItem, integer ) RETURNS numeric AS
$$
    SELECT $1.unitPrice * $2 AS stockValue;
$$ LANGUAGE SQL;

Which one of the following SELECT statements will produce a list of stock items on hand and the stock value, from the stockOnHand table?

  1. SELECT item.name AS item_name, item.supplierID AS supplier,
       item.unitPrice AS unit_price, quantity, stockValue(item, quantity)
FROM stockOnHand;
  2. SELECT (stockOnHand.item).name AS item_name,
       (stockOnHand.item).supplierID AS supplier,
       (stockOnHand.item).unitPrice AS unit_price,
       quantity, stockValue(item, quantity)
FROM stockOnHand;
  3. SELECT name AS item_name, supplierID AS supplier,
       unitPrice AS unit_price, quantity,
       stockValue(item, quantity)
FROM stockOnHand;
  4. SELECT item.name AS item_name, item.supplierID AS supplier,
       item.unitPrice AS unit_price, item.quantity, item.stockValue(item, quantity)
FROM stockOnHand;

The paper prints the dollar sign as the word “dollar” (restored here as $). It also prints CREATE TYPE_InventoryItem with an underscore, which is a typo for CREATE TYPE InventoryItem.

Show answer Memo

b. item is a column whose value is a composite type. To reach a field inside a composite column PostgreSQL needs the column in parentheses followed by a dot: (stockOnHand.item).name.

Option a writes item.name, which PostgreSQL reads as “table item, column name” and fails. Option c uses name, supplierID and unitPrice as if they were top-level columns of stockOnHand. Option d calls item.quantity and item.stockValue(...), which do not exist. In option b the function call stockValue(item, quantity) works because it takes the whole composite value and the integer.

Show answer Study answer

ObjectDB creates the database file the first time you open it, so “creating” the database means obtaining the factory for a file called COS326.odb and then an entity manager from it:

Question 223 marksObject relational DBMSPDF p.13 ↗

Study the following SQL statements and answer the question which follows.

CREATE TYPE TitleType AS ENUM ('Prof','Dr','Ms','Mev','Miss','Mr','Mnr',);
CREATE TYPE StaffType AS (title TitleType, firstName CHAR(20), surname CHAR(20));
CREATE TABLE staffMember (staff StaffType, department CHAR(20));

Write the SQL function called StaffName which returns a string with the title, first name and last name of a staff member (3 Marks).

Show answer Study answer

The function takes a StaffType value and joins the three fields with spaces. The enum is cast to text so it can be concatenated; TRIM removes the padding that CHAR(20) adds.

CREATE FUNCTION StaffName( StaffType ) RETURNS text AS
$$
    SELECT $1.title::text || ' ' || TRIM($1.firstName) || ' ' || TRIM($1.surname);
$$ LANGUAGE SQL;

-- use it:
SELECT StaffName(staff) FROM staffMember;

Marking points: correct header and return type, $$ ... $$ LANGUAGE SQL, accessing composite fields with $1.field, and concatenation with ||.

The printed CREATE TYPE TitleType has a trailing comma after 'Mnr', which PostgreSQL would reject; assume it is a typo.

Question 266 marksData warehousingPDF p.15 ↗

With an aid of an example, describe the Star Schema.

Show answer Study answer

A star schema is the relational (ROLAP) way of storing a dimensional model. It has one central fact table surrounded by dimension tables, so a diagram looks like a star.

  • Fact table: each row records one business event at a stated grain and holds the numeric measures (the values you add up) plus a foreign key to each dimension.
  • Dimension tables: describe the context of the facts (who, what, where, when). They are usually denormalised, with hierarchies such as Hotel → Province → Hotel line kept in one table.
  • Links: each dimension joins to the fact table in a one-to-many relationship (one dimension row, many fact rows).
  • Why used: simple queries with few joins, fast aggregation and an easy picture for business users.

Example: hotel occupancy (the schema in Question 35):

            TIME (Time_Key, Year, Quarter, Month)
                     |
HOTEL ---- OCCUPANCY_FACTS ---- RM_TYPE
(Hotel_Key,   (Time_Key, Hotel_Key, Room_Key,   (Room_Key,
 Province,     Occupied_rooms, Vacant_rooms,      Room_Type, Size)
 Branch ...)   Revenue)

To find revenue by province and month for 2022 you join the fact table to HOTEL and TIME on the key columns and sum Revenue.

Question 276 marksOLAPPDF p.16 ↗

Name and describe with an aid of a SQL query example of any SQL extension for aggregation you know of.

Show answer Study answer

GROUP BY CUBE (the SQL OLAP extensions are CUBE, ROLLUP and GROUPING SETS). CUBE computes the aggregate for every combination of the listed grouping columns in a single statement, so you get the detail rows, all the subtotals and the grand total without writing several queries joined by UNION.

SELECT B.province, T.month, SUM(S.revenue) AS total_revenue
FROM   BRANCH B, TIME T, SALES S
WHERE  T.year = 2022
AND    B.BranchKey = S.BranchKey
AND    T.TimeKey   = S.TimeKey
GROUP BY CUBE (B.province, T.month);

With two grouping columns this produces 2² = 4 groupings:

  • {province, month, SUM}: revenue for each province in each month
  • {province, SUM}: each province’s total over all months (month is NULL)
  • {month, SUM}: each month’s total over all provinces (province is NULL)
  • {all, SUM}: the grand total (both NULL)

The others: ROLLUP (province, month) gives only the hierarchical subtotals (detail, province total, grand total), and GROUPING SETS produces exactly the groupings you list.

Question 293 marksObject ODBMSPDF p.17 ↗

Study the following scenario and the following question:

You have been called for a software developer interview at XYZ software solutions. In the interview, you had mentioned that you studied and utilised Object-Oriented databases. The interview panel then decided to test your proficiency in using Object-Oriented databases.

Explain to the interview panel with an aid of a Java code example, what the TypedQuery interface is and its functions in Object-Oriented Databases.

Show answer Study answer

TypedQuery<T> is the JPA 2 interface for running JPQL queries whose result type is known. It extends the older Query interface. You obtain one from the EntityManager by passing the result class as the second argument to createQuery.

EntityManager em = emf.createEntityManager();

TypedQuery<Student> q = em.createQuery(
    "SELECT s FROM Student s WHERE s.age < :age", Student.class);
q.setParameter("age", 22);                 // bind the named parameter
List<Student> results = q.getResultList(); // no cast needed

for (Student s : results) {
    System.out.println(s.getName());
}

Functions:

  • Executes the query and returns typed results: getResultList() returns List<Student> and getSingleResult() returns one Student, with no casting.
  • The compiler and IDE know the result type, so type errors are caught at compile time (a plain Query returns Objects).
  • Supports parameters (setParameter), paging (setFirstResult, setMaxResults) and locking options.

This scenario builds up from the scenario in Question 29. You are still in the interview at XYZ software solutions. You had also mentioned that you studied and used Object RDMS. The interview panel have then decided to test your proficiency again in using Object RDMS. They provide you with the following trigger function:

CREATE FUNCTION delete_audit() RETURNS TRIGGER AS
$$ BEGIN
        INSERT INTO DeletedBooking SELECT OLD.*, today, now, user;
        RETURN OLD;
   END
$$ LANGUAGE plpgsql;

(a) Explain in detail to the interview panel what the function does? (2 Marks)

(b) Create a trigger statement so that the function of (a) above is used to perform the necessary actions after a row is deleted from the specified table (2 Marks)

The paper prints $$ as “dollar dollar”, restored here. The scan prints OLD*; the course notes’ version of this trigger uses OLD.*.

Show answer Study answer

(a) delete_audit() is a trigger function that keeps an audit log of deleted rows. When a row is deleted, it inserts a copy of that row into the audit table DeletedBooking. OLD.* stands for all the column values of the row that was just deleted (a DELETE has no NEW row). It adds the date and time of the deletion (the printed today and now) and the database user who did it (user) as extra columns, so you know what was deleted, when and by whom. RETURN OLD follows the convention for delete triggers.

(b) The table is not named in the scenario; the audit table name suggests a Booking table:

CREATE TRIGGER audit_deleted_booking
    AFTER DELETE ON Booking
    FOR EACH ROW
        EXECUTE FUNCTION delete_audit();

AFTER DELETE runs the function once the delete has happened, and FOR EACH ROW runs it for every deleted row. (Older PostgreSQL versions write EXECUTE PROCEDURE.)

In real PostgreSQL the date and time would be written current_date, now() or just now(); today is not a PostgreSQL keyword. The intent is what matters in the answer.

Module codes beginning COS3 are third-year modules.

for $s in //student
where starts-with($s/@module, "COS3") and number($s/age) < 22
return $s/name

Third-year students are COS326 (18), COS333 (21), COS301 (24) and COS314 (23). Those under 22: Sheunesu Makura and Thando Mandela.

Study the following scenario and the following questions:

You have a friend studying MongoDB. Your friend has showed you the following collection called myfavourites within MongoDB:

{ _id: 5, type: "food", item: "cake",     ratings: [ 5, 8, 9 ] }
{ _id: 6, type: "food", item: "chicken",  ratings: [ 5, 9 ] }
{ _id: 7, type: "food", item: "biscuits", ratings: [ 9, 5, 8 ] }
{ _id: 8, type: "food", item: "steak",    ratings: [ 5, 8, 9 ] }

The name of the MongoDB database is called foods. Write the JavaScript statement for the mongo shell that does the following:

a. List all documents where the field ‘ratings’ holds exactly three elements, 5, 8, 9, in this order (2 Marks)

b. List all documents where ‘ratings’ contains 5 as one of its elements (1 Mark)

c. List all documents where the ratings array contains at least one element that is greater than 5 and less than 9: (3 Marks)

Show answer Memo

After use foods:

(a) An array given as the value must match exactly, same elements in the same order:

db.myfavourites.find({ ratings: [5, 8, 9] })

Returns cake and steak. Biscuits has the same numbers in a different order, and chicken has only two.

(b) A plain value against an array field matches if the array contains it:

db.myfavourites.find({ ratings: 5 })

All four documents contain 5.

(c) $elemMatch makes both conditions apply to the same element:

db.myfavourites.find({ ratings: { $elemMatch: { $gt: 5, $lt: 9 } } })

Returns cake, biscuits and steak, which each contain 8. Chicken [5, 9] has nothing strictly between 5 and 9. Without $elemMatch, { ratings: { $gt: 5, $lt: 9 } } could be satisfied by two different elements, and chicken would wrongly match (9 is greater than 5, and 5 is less than 9).

Study the following scenario and the following questions:

You have been provided with the following Cypher query, assumed already executed in a Neo4j database:

CREATE
   ( psX:Person { name: "Xolisa", from: "Joburg"} ),
   ( psK:Person { name: "Katlego", from: "Pretoria"} ),
   ( cb1:Club { name: "Sundowns"} ),
   ( cb2:Club { name: "Kaizer Chiefs"}),

   ( psX)-[:KNOWS { since: 2014 } ]->(psJ ),
   ( psX)-[:SUPPORTS { since: 2015 } ]->(cb1 ),
   ( psK)-[:SUPPORTS { since: 2014 } ]->(cb2 );

a. Write the CYPHER query to update the nodes for clubs with a new property called points with values 25 (for Sundowns), and 20 (for Kaizer Chiefs). (3 Marks)

b. Write the CYPHER query that utilises a mathematical function that calculates the difference between the points of Sundowns and Kaizer Chiefs. (3 Marks)

Show answer Memo

(a)

MATCH (s:Club {name: "Sundowns"}), (k:Club {name: "Kaizer Chiefs"})
SET s.points = 25, k.points = 20
RETURN s, k;

(Two separate MATCH ... SET statements also work.)

(b) The mathematical function is abs(), which gives the difference as a positive number whichever club is ahead:

MATCH (s:Club {name: "Sundowns"}), (k:Club {name: "Kaizer Chiefs"})
RETURN abs(s.points - k.points) AS pointsDifference;

Result: 5. Plain s.points - k.points also gives 5 here, but abs() is the function the question asks for.

This needs the points from part (a) to have been set first.

Question 346 marksData warehousingPDF p.20 ↗

Study the following scenario and the following questions:

A local firm utilises data warehousing. You have been provided by the firm with the following figure which explains some of their business operations.

The figure (PDF page 21) shows a cube split into two quarters, Qtr1 (R20m) and Qtr2, with an arrow labelled “Drill-down” pointing right to a cube split by month with Jan R5m, Feb R10m and Mar R5m, and an arrow labelled “Roll-up” pointing back left.

a. What is the name of the shape depicted in the figure above in terms of data warehousing? (2 Marks)

b. Describe in detail the two operations shown in figure. Include the values shown in the figure your description (4 Marks)

Show answer Study answer

(a) A data cube (a multidimensional or OLAP cube; with more than three dimensions it is a hypercube). Each axis is a dimension, such as time, and each cell holds a measure, such as revenue.

(b)

  • Drill-down moves down a dimension hierarchy to more detailed data. Drilling down from the quarter level to the month level breaks Qtr1 = R20m into Jan R5m, Feb R10m and Mar R5m.
  • Roll-up is the reverse: it moves up the hierarchy to a more summarised level by aggregating. Rolling up the three months gives R5m + R10m + R5m = R20m for Qtr1.

The detail always adds up to the summary: 5 + 10 + 5 = 20.

SELECT H.province, T.month, SUM(C.revenue) AS revenue_sum
FROM   OCCUPANCY_FACTS C, HOTEL H, TIME T, RM_TYPE R
WHERE  R.Room_Type = 'single' AND
       T.year = 2022
       AND C.Hotel_Key = H.Hotel_Key
       AND C.Time_Key  = T.Time_Key
       AND C.Room_Key  = R.Room_Key
GROUP BY CUBE ( H.province, T.month );

Show answer Study answer

(a) The two types of predictive model are classification and regression (value prediction).

  • Classification learns from records with a known class and predicts a categorical (discrete) class label for a new record, for example whether a customer is a low, medium or high credit risk. Decision trees are a common technique.
  • Regression (value prediction) predicts a continuous numeric value from other variables using an equation such as y = f(x1, ..., xn), for example estimating a customer’s income.

In both, a dependent (target) variable is predicted from independent (predictor) variables.

(b)

ModelTarget (dependent) variablePredictor (independent) variables
ClassificationCredit-Risk (low / medium / high)Age, Gender, Income, Dependants
RegressionA numeric column, for example IncomeAge, Gender, Dependants (and Credit-Risk)

Credit-Risk is categorical, so it can only be the target of the classification model; the regression target has to be one of the numeric columns (Age, Income or Dependants).

Any sensible numeric column could be named as the regression target; Income is one example.
