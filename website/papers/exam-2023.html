Question 11 markObject ODBMSPDF p.3 ↗

In ObjectDB, the object identifier (OID) needs to be immutable. What does this mean?

  1. The OID value of the particular object can be generated automatically.
  2. The OID value of the particular object should not change.
  3. The OID value can be used by more than one object.
  4. By immutable it means the OID value can be used in database tables
Show answer Study answer

b. Immutable means the OID of an object must never change during its lifetime, so it can always be used to find that object. An OID is also unique to one object (not shared), and it is generated by the system, but neither of those is what “immutable” means.

Question 21 markObject relational DBMSPDF p.3 ↗

Study the following SQL statements and answer the question that follows:

CREATE SEQUENCE venueSeq START 101;
CREATE TYPE BuildingCodeType AS ENUM ('IT', 'LAW', 'CHM', 'PHY');
CREATE TYPE RoomCodeType AS (building BuildingCodeType, floor int, room int);
CREATE TYPE EquipmentType AS ENUM ('projector', 'PAsystem', 'safe', 'PC', 'phone');
CREATE TABLE Venue (
    venueKey integer DEFAULT nextval('venSeq') PRIMARY KEY,
    venueCode RoomCodeType, seats int );
CREATE TABLE LectureRoom ( equipmentList text [ ] ) INHERITS (VENUE);

Assuming that the above SQL statements have been executed in a PostgreSQL database, which one of the SQL statements below will insert the data shown below into the LectureRoom table?

VenueKey: auto-generated
venue code: IT 4-2
seats: 120
equipment: projector, PAsystem, safe
  1. INSERT INTO LectureRoom( venueCode, seats, equipmentList)
VALUES ( ('IT', 4,2), 120, ['projector', 'PAsystem', 'safe']);
  2. INSERT INTO LectureRoom venueCode, seats, equipmentList)
       ( 'IT', 4,2, 120, ARRAY['projector', 'PAsystem', 'safe']);
  3. INSERT INTO LectureRoom ( venueCode, seats, equipmentList)
VALUES ( ('IT', 4,2), 120,
         ARRAY['projector','PAsystem', 'safe'] );
  4. INSERT INTO LectureRoom ( venueCode, seats, equipmentList)
VALUES ( ('IT', 4,2, 120),
         ARRAYS['projector','PAsystem', 'safe'] );

As printed, the sequence is created as venueSeq but the default calls nextval('venSeq'), so the schema would fail as written. Assume it is a typo; it does not change the answer.

Show answer Memo

c. The composite value goes in a row constructor ('IT', 4, 2), the array uses the ARRAY[ ... ] constructor, and venueKey is left out so the sequence default fills it in.

Question 81 markBig dataPDF p.8 ↗

Which one of the following technologies bridges the gap between declarative-style interfaces such as SQL, and rigid style required by MapReduce?

  1. HDFS
  2. Apache Hive
  3. HBase
  4. Apache Pig
Show answer Study answer

d. Apache Pig. Pig Latin is a high-level data-flow language that sits between the declarative style of SQL and the low-level, rigid map-then-reduce style of raw MapReduce; Pig turns the scripts into MapReduce jobs.

HDFS is the Hadoop file system and HBase is a wide-column store. Hive gives a SQL-like language (HiveQL) on Hadoop, which is itself the declarative side rather than the bridge.

Your lecture notes mention Pig and Hive only briefly, so this answer rests on how Pig Latin is usually described. Treat it as the best fit.

Question 213 marksObject ODBMSPDF p.11 ↗

With the aid of examples, differentiate between JPQL / Criteria Variables and JPQL / Criteria Literals in ObjectDB. (3 Marks)

Show answer Study answer

Both are atomic query expressions, the smallest building blocks of a JPQL or Criteria query.

Variables are names that stand for objects the query ranges over. The range variable c in FROM Country c is bound to each Country entity in turn, so its value changes as the query runs. In the Criteria API the equivalent is the Root<Country> c = q.from(Country.class).

Literals are fixed constant values written directly into the query: numbers, strings, TRUE/FALSE and NULL. They stay the same on every execution.

SELECT c FROM Country c WHERE c.population > 1000000 AND c.name <> 'Canada'
--                ^ variable          ^ literal (number)        ^ literal (string)

In Criteria terms, c is a variable and 1000000 is a literal (cb.literal(1000000)).

A third kind, parameters (:minGpa or ?1), are placeholders whose value is supplied at run time with setParameter, so they are neither variables nor literals.

CREATE TABLE Persons (

Write the PL/pgSQL function called calculate_average which calculates the average age of the people in the Persons table. (4 Marks)

CREATE OR REPLACE FUNCTION calculate_average()
RETURNS numeric AS $$
DECLARE
    avg_age numeric;
BEGIN
    SELECT AVG(age) INTO avg_age FROM Persons;
    RETURN avg_age;
END;
$$ LANGUAGE plpgsql;

Question 257 marksNeo4jPDF p.13 ↗

Study the following Cypher query and answer the questions that follow:

CREATE (braam:User {name: 'braam', age: 30})
CREATE (phathutshedzo:User {name: 'phathutshedzo', age: 28})
CREATE (loyiso:User {name: 'loyiso', age: 35})
CREATE (dave:User {name: 'Dave', age: 40})

CREATE (braam)-[:KNOWS]->(phathutshedzo)
CREATE (braam)-[:KNOWS]->(loyiso)
CREATE (phathutshedzo)-[:KNOWS]->(dave)

a. What are predicates in the Cypher query language? Give two examples of predicate functions. (3 Marks)

b. Write the CYPHER query to count the number of persons who have an age of 35 or below. Make use of one predicate function. (4 marks)

Show answer Study answer

(a) Predicates are functions that return true or false for the input they are given. They are used mainly to filter the matched subgraph in the WHERE part of a query (or to return a true/false column). Examples:

  • exists() tests whether a property or a pattern exists, for example exists((n)-[:KNOWS]->()).
  • all(), any(), none() and single() test a condition over a list: all, at least one, none, or exactly one element satisfies it.

(b)

MATCH (u:User)
WHERE exists(u.age) AND u.age <= 35
RETURN count(u) AS total;

exists(u.age) is the predicate, making sure the user has an age, and u.age <= 35 is the comparison. Result: 3 (braam 30, phathutshedzo 28 and loyiso 35; Dave at 40 is excluded).

In Neo4j 5 and later exists(u.age) on a property is replaced by u.age IS NOT NULL. Another predicate-based version for any version is WHERE any(a IN [u.age] WHERE a <= 35).

Question 267 marksBig data & data miningPDF p.14 ↗

(a) Mention three advantages of the Hadoop/MapReduce Technology (no one word answers). (3 Marks)

(b) Elaborate on at least three ways to describe the knowledge discovered during data mining (no one word answers). (4 Marks)

Show answer Study answer

(a) Any three of:

  • Scalability: a cluster grows by adding cheap commodity machines (horizontal scaling), so very large datasets can be stored and processed.
  • Fault tolerance: HDFS keeps replicas of each block and failed tasks are re-run on other nodes, so a node failure does not lose the job.
  • Parallel processing close to the data: map tasks run on the nodes that hold the data, which cuts network transfer and speeds up big batch jobs.
  • Flexibility: it handles structured, semi-structured and unstructured data without a fixed schema.
  • Low cost: open source software running on commodity hardware.

(b) Knowledge discovered by data mining can be described as, for example:

  • Association rules: rules of the form X ⇒ Y with support and confidence, such as customers who buy bread also buy milk.
  • Classification hierarchies: a tree (such as a decision tree) that assigns items to classes using their attributes, for example approving or rejecting a loan.
  • Sequential patterns: events that follow each other over time, such as what a customer buys after a first purchase.
  • Patterns within time series: similar behaviour over time, for example stock prices that rise and fall together.
  • Clustering: grouping records into clusters of similar items without predefined classes.

Question 294 marksObject RDBMSPDF p.15 ↗

Study the following SQL statements and answer the question which follows.

CREATE TYPE YearLevelType AS ENUM ('First','Second','Third','Honours','Masters','PhD',);

Write the SQL function called StudentName which returns a string with the title, first name and last name of a student member. (4 Marks)

Show answer Study answer
CREATE FUNCTION StudentName( StudentType ) RETURNS text AS
$$
    SELECT $1.title::text || ' ' || TRIM($1.firstName) || ' ' || TRIM($1.surname);
$$ LANGUAGE SQL;

-- use it:
SELECT StudentName(student) FROM studentMember;

The function takes a StudentType value, reads its fields with $1.field, casts the enum to text and joins the three parts with spaces. TRIM removes the padding from the CHAR(20) columns.

Question 304 marksSemi-structured data & XMLPDF p.15 ↗

Study the following scenario and the following question:

Martin is busy with a BaseX practical. In the practical, Martin has been provided with the following XML schema. Assist Martin to answer the following questions.

<?xml version="1.0" encoding="UTF-8"?>
<xs:schema xmlns:xs="http://www.w3.org/2001/XMLSchema">
  <xs:element name="Person">
    <xs:complexType>
      <xs:sequence>
        <xs:element name="FirstName" type="xs:string"/>
        <xs:element name="LastName" type="xs:string"/>
        <xs:element name="Age" type="PositiveInteger"/>
      </xs:sequence>
    </xs:complexType>

(a) What is the difference between XML schema and XML DTD? (2 Marks)

(b) Identify the two types of XML schema elements in the above scenario? (2 Marks).

Show answer Memo

(a) An XML Schema (XSD) is written in XML itself and describes structure and data types (string, integer, date and so on), with fine control over how often an element occurs (minOccurs, maxOccurs) and support for namespaces. A DTD uses its own non-XML syntax, has very limited typing (essentially just text) and no namespace support, so it is less expressive.

(b) Complex type and simple type elements:

  • Complex type: Person is a complex type because it contains child elements (a sequence of FirstName, LastName and Age).
  • Simple type: FirstName, LastName and Age are simple types; each holds only scalar text content (xs:string, and a positive integer for Age).

The schema as printed uses type="PositiveInteger" with no xs: prefix and the built-in type is spelled xs:positiveInteger, so it would not validate as written.

a. What are ranking functions, and what are they used for in OLAP? (3 Marks)

Show answer Study answer

(a) Ranking functions are SQL OLAP (window) functions that compute the rank of a row compared with the other rows in the result, based on the values of one or more measures. Examples are RANK() (ties share a rank and the next rank is skipped), DENSE_RANK() (ties share a rank with no gaps), and also percent rank and N-tiles. They are used to answer questions such as the top or bottom stores, products or customers without sorting and counting by hand.

(b)

SELECT branch_ID, city, net_profit,
       RANK() OVER (ORDER BY net_profit DESC) AS profit_rank
FROM   ttech_profits;
