Question 11 markOODBMSPDF p.3 ↗

Which limitation of RDBMSs is most directly addressed by the use of Object

          Identifiers (OIDs) in OODBMSs?
  • A. Limited operations
  • B. Semantic overloading
  • C. Poor representation of real -world entities
  • D. Homogeneous data structure
Show answer Study answer

B. OIDs give every object a unique, system-generated identity separate from its attribute values. That solves semantic overloading: the relational model has one construct (the relation) for both data and relationships and cannot tell relations from relationships. Your notes list this as the weakness OIDs fix.

Nothando writes SELECT c FROM Customer c JOIN c.orders o WHERE o.total > 500. What does this query do?

  • A. Retrieves customers with more than 500 orders

Question 31 markJPQLPDF p.3 ↗

You want to update a product’s price in JPQL. Which query is correct?

  • A. UPDATE Product SET price = 200 WHERE id = 1
  • B. MODIFY Product SET price = 200 WHERE id = 1
  • C. SET Product.price = 200 WHERE Product.id = 1
  • D. UPDATE Product p SET p.price = 200 WHERE p.id = 1
Show answer Study answer

D. A JPQL update names the entity and an identification variable: UPDATE Product p SET p.price = 200 WHERE p.id = 1. There is no MODIFY statement, and the other forms are not valid JPQL.

Option A (UPDATE Product SET ... without an alias) is also accepted by many JPA providers; D is the standard form with an alias.

Question 2115 marksObject DBMS / JPAPDF p.8 ↗

Object DBMS

  • a. Evaluate the pros and cons of embedding OODB constructs directly into host languages versus extending SQL with OO features. (4 marks)
  • b. Forensic investigators log evidence over several days. You need to support long -
lived transactions. The following code snippet begins and commits a transaction:
EntityTransaction tx = em.getTransaction();
tx.begin();
// persist multiple EvidenceItem objects
tx.commit();

Modify the above snippet to include rollback logic in case of failure. (6 marks)

(c) Briefly explain what a Semantic Information Manager is and how it differs from traditional relational or object databases. (5 marks)

Show answer Study answer

(a) Embedding OODB constructs in a host language (strategy 3, such as O2 with C): pros are seamless use of objects in the programming language with no impedance mismatch; cons are tying the database to one language, no standard declarative query language and a small installed base. Extending SQL with OO features (ORDBMS / Object SQL): pros are keeping the relational installed base, skills, tools and declarative querying, with gradual migration; cons are a more complex SQL and a less natural, still partly mismatched object model.

(b)

EntityTransaction tx = em.getTransaction();
try {
    tx.begin();
    // persist multiple EvidenceItem objects
    // em.persist(item);
    tx.commit();
} catch (RuntimeException ex) {
    if (tx.isActive()) {
        tx.rollback();
    }
    throw ex;
}

Commit only after all the work succeeds; on any exception roll back the active transaction so no partial evidence is stored. For a long-lived transaction the same pattern applies across the days the transaction stays open.

(c) The Semantic Information Manager (SIM) is an example of an OODBMS strategy that develops a novel database data model and language from scratch. It is a semantic data model of classes, generalisation (inheritance) and relationships, queried through a high-level language. It differs from a relational database (no tables and joins; relationships are modelled directly) and from an object database that extends an OOP language (it is not tied to one). Its downside is no installed base or skills.

Your notes only name SIM as the example of “develop a novel data model/language”. The extra description in (c) is from general knowledge; check it against your slides.

ORDBMS

Study the following SQL statements and answer the following questions:
 CREATE TABLE transactions (
     account_id serial PRIMARY KEY,
     changes numeric[]
 );
 INSERT INTO transactions (changes) VALUES
     (ARRAY[100, -50, 200, -30]),
     (ARRAY[-10, 20, 30]),
     (ARRAY[50, 100, -25, -25]);

You have executed the above statements in PostgreSQL, and they ran successfully.

(a) Complete the function to sum only positive changes .

 CREATE ________ sum_positive_changes(changes numeric[])
 RETURNS NUMERIC AS $$
 _________
     total numeric := 0;
     val numeric;
 BEGIN
     ______ ____ IN ARRAY changes
     _______
         IF val > 0 THEN
             ________;
         END IF;
     END _______;
     RETURN _______;
 END;
 $$ ___________;
                                                       (10 marks)
(b) Write the select statement to display account_id and sum of positive changes.

(1 Marks)

(c) Compare the limitations of traditional RDBMSs with the extended capabilities of ORDBMSs like PostgreSQL. Focus on support for complex types, inheritance, and

procedural logic. (5 Marks)

Show answer Study answer

(a) Blanks completed:

CREATE FUNCTION sum_positive_changes(changes numeric[])
RETURNS NUMERIC AS $$
DECLARE
    total numeric := 0;
    val numeric;
BEGIN
    FOREACH val IN ARRAY changes
    LOOP
        IF val > 0 THEN
            total := total + val;
        END IF;
    END LOOP;
    RETURN total;
END;
$$ LANGUAGE plpgsql;

(b)

SELECT account_id, sum_positive_changes(changes) AS positive_total
FROM transactions;

Results: 300, 50 and 150.

(c) Complex types: an RDBMS holds only atomic values in columns; an ORDBMS such as PostgreSQL adds composite types, arrays and enumerations. Inheritance: an RDBMS has none; PostgreSQL has table inheritance (INHERITS). Procedural logic: an RDBMS offers only declarative SQL; PostgreSQL adds user-defined functions, procedures and triggers in PL/pgSQL, so logic can run inside the database.

Question 2415 marksOODBMS / JPAPDF p.11 ↗

OODBMS

Study the following scenario and answer the following questions:

Jacob is developing a ride -hailing app using ObjectD B. The ride-hailing app tracks

 rides and each ride has:
   •  driverName: String.
   •  passengerName: String.
   •  distance: Double (km travelled).
   •  completed: Boolean (true if the ride has ended).
Help Jacob fulfil the following objectives:
  (a) Write the Ride entity class. (5 Marks)
  (b) Implement addRide method to add a new ride . (3 Marks)
  (c) Provide a JPQL query to find all rides longer than 10km and completed,
    explain why JPQL helps here. (3 Marks)
(d) Write listLongRides method to list the long rides . (4 Marks)
Show answer Study answer

(a)

@Entity
public class Ride {
    @Id @GeneratedValue
    private Long id;
    private String driverName;
    private String passengerName;
    private Double distance;
    private Boolean completed;

    public Ride() {}
    public Ride(String driverName, String passengerName, Double distance, Boolean completed) {
        this.driverName = driverName; this.passengerName = passengerName;
        this.distance = distance; this.completed = completed;
    }
}

(b)

public void addRide(EntityManager em, Ride ride) {
    em.getTransaction().begin();
    em.persist(ride);
    em.getTransaction().commit();
}

(c)

SELECT r FROM Ride r WHERE r.distance > 10 AND r.completed = true

JPQL helps because it queries the entity and its fields (Ride, distance), not tables and columns, so it is object-oriented, independent of how the data is stored and returns real Ride objects.

(d)

public List<Ride> listLongRides(EntityManager em) {
    TypedQuery<Ride> q = em.createQuery(
        "SELECT r FROM Ride r WHERE r.distance > 10 AND r.completed = true", Ride.class);
    return q.getResultList();
}
Question 2515 marksPL/pgSQL / triggersPDF p.11 ↗

ORDBMS

Study the following scenario and answer the following questions:

A retail company stores quarterly sales figures in an array column sales_by_quarter in the employees table. The database includes a predefined function total_sales(sales INTEGER[]) that calculates the total annual

sales from the array. You are asked to use this function and implement logic that ensures the

annual_sales column is automatically updated whenever a new employee is inserted or their sales_by_quarter array is modified.

Questions:

  • a. Explain one advantage and one limitation of using arrays in object -relational databases. (4 Marks)
  • b. Write a query that uses the total_sales function to display employee names

and their total annual sales. ( 2 Marks)

(c) Complete the trigger function that automatically updates the annual_sales column whenever a new employee is inserted or their sales_by_quarter is

updated. ( 4 Marks)
CREATE FUNCTION update_annual_sales() RETURNS ________ AS $$
BEGIN
    NEW.annual_sales := ____________(NEW.sales_by_quarter);
    RETURN _______;
END;
$$ ____________;
(d) Complete the trigger that calls the function before insert or update. (5 Marks)
CREATE ________ update_sales_trigger
__________ employees
FOR ________ OR ________
______________ update_annual_sales();
Show answer Study answer

(a) Advantage: an array stores several related values (such as four quarterly figures) in one column of one row, so no extra table or join is needed and the data is compact and easy to read together. Limitation: arrays break the first-normal-form idea of atomic values; individual elements are harder to query, index, constrain and update, and the design is less portable.

(b)

SELECT name, total_sales(sales_by_quarter) AS annual_sales
FROM employees;

(c)

CREATE FUNCTION update_annual_sales() RETURNS TRIGGER AS $$
BEGIN
    NEW.annual_sales := total_sales(NEW.sales_by_quarter);
    RETURN NEW;
END;
$$ LANGUAGE plpgsql;

(d)

CREATE TRIGGER update_sales_trigger
BEFORE INSERT OR UPDATE ON employees
FOR EACH ROW
EXECUTE FUNCTION update_annual_sales();

A BEFORE row-level trigger can change NEW and return it; an AFTER trigger cannot change the stored row. The printed skeleton for (d) is garbled in the PDF text; the complete statement above is the answer.

Question 2610 marksXML SchemaPDF p.12 ↗

Semi -structured Data and XML

Study the following scenario and answer the following questions:

A company wants to validate their XML files containing employee records. Each

 record must include the following:
   •  Name (string),
   •  Department (string), and
   •  Salary (decimal).

They require that every employee must have a department and the salary must not

be negative.

  • a. Identify the XML schema type (simple, complex, or global) that is most appropriate for defining an employee element and justify your choice. (3 Marks)
  • b. Write an XML Schema Definition (XSD) snippet for the employee element,

enforcing the constraints mentioned above.(4 Marks)

Hint: You can use a structure similar to this: <xs:element name="elementName">

   <xs:________>
      <xs:sequence>
         <!-- child elements go here -->
      </xs:sequence>
   </xs:__________>

</xs:element>

(c) Explain why XML Schema is preferred over DTD in this scenario. (3 Marks)

                                             End of Semester Test Paper
Show answer Study answer

(a) The best fit is a complex type: an employee element contains several child elements (Name, Department, Salary), and only a complex type can contain child elements. Simple types hold only text. A global element is one declared at the top level of the schema (it can be reused); it describes where it is declared, not a kind of content.

(b)

<xs:element name="employee">
  <xs:complexType>
    <xs:sequence>
      <xs:element name="Name" type="xs:string"/>
      <xs:element name="Department" type="xs:string" minOccurs="1"/>
      <xs:element name="Salary">
        <xs:simpleType>
          <xs:restriction base="xs:decimal">
            <xs:minInclusive value="0"/>
          </xs:restriction>
        </xs:simpleType>
      </xs:element>
    </xs:sequence>
  </xs:complexType>
</xs:element>

The blank in the hint is complexType. minOccurs="1" makes Department required, and the restriction with minInclusive 0 forbids negative salaries.

(c) XSD can restrict values (such as a decimal that must not be negative) and control how often elements occur, which a DTD cannot do because it has almost no data types. XSD is itself written in XML, supports namespaces, and is more extensible and reusable, so it is better for validating this data.
