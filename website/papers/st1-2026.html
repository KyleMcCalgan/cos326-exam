(b) PostgreSQL trigger and array average 4.5/7

Your answer

CREATE FUNCTION average_energy() RETURN TRIGGER AS
$$
DECLARE
val NUMERIC
count int := 0
sum NUMERIC := 0
BEGIN
FOR EACH val IN ARRAY NEW.state_energy
    LOOP
    sum := sum + val;
    count := count + 1;
    END LOOP

NEW.average_energy := sum / count;
RETURN NEW;
END
$$langauge pspgsql

CREATE TRIGGER average_energy_trigger
BEFORE INSERT on AuvEnergy

Memo

CREATE FUNCTION calculate_average_energy()
RETURNS TRIGGER AS $$
DECLARE
    energy NUMERIC;
    total_energy NUMERIC := 0;
    reading_count INTEGER := 0;
BEGIN
    FOREACH energy IN ARRAY NEW.stage_energy LOOP
        total_energy := total_energy + energy;
        reading_count := reading_count + 1;
    END LOOP;
    NEW.average_energy := total_energy / reading_count;
    RETURN NEW;
END;
$$ LANGUAGE plpgsql;

CREATE TRIGGER calculate_auv_average
BEFORE INSERT OR UPDATE ON AUVEnergy
FOR EACH ROW
EXECUTE FUNCTION calculate_average_energy();

Where the marks went

What you did: You attempted a running sum and count, assigned the average to NEW, returned NEW and wrote a row-level BEFORE trigger. The structure shows you understood the task.

What to fix: Use RETURNS TRIGGER, semicolons on declarations and statements, FOREACH as one word, and the given NEW.stage_energy rather than NEW.state_energy. The trigger must cover both INSERT OR UPDATE. Finish the function with END; and LANGUAGE plpgsql;.

The question assumes at least one array value; this example also assumes the elements are non-null. Test mentally with [10, 20, 30]: sum 60, count 3, average 20. Rubric: function 1, iteration 2, average 2, assign and return 1, trigger 1.
